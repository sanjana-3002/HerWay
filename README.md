# HerWay — Chicago Neighborhood Safety Platform

A full-stack platform that analyzes Reddit posts, city crime records, and 311 service requests to map neighborhood-level safety conditions in Chicago — with a focus on women's experiences.

**Live app:** [her-way-soremo.vercel.app](https://her-way-soremo.vercel.app/)

**Author:** Sanjana Waghray  
**Institution:** Illinois Institute of Technology  
**Course:** Soremo Initiative

---

## What This Project Does

Most safety tools rely only on official crime numbers. HerWay layers in real community voices from Reddit to capture what people — especially women — actually experience on the ground: fear of walking alone at night, street harassment, avoiding certain areas. The result is an interactive map that combines three data sources into a single awareness score per neighborhood, plus an AI chatbot you can ask anything about any Chicago neighborhood.

---

## Live Features

- **Interactive map** — 77 Chicago neighborhoods colored by risk level, click any one to get a full breakdown
- **Neighborhood details panel** — crime stats, Reddit community sentiment, 311 infrastructure data side by side
- **Search bar** — type a neighborhood name and fly to it on the map
- **HerWay chatbot** — ask anything ("what's it like at night in Logan Square?", "which areas have the most community concern?") and get a grounded, data-backed answer
- **Filter controls** — switch between risk views and data layers

## Data Sources

| Source | File | What It Captures |
|--------|------|-----------------|
| Reddit posts | `data/raw/chicago_safety_reddit.csv` | 1,218 posts from r/chicago, r/AskChicago, r/TwoXChromosomes |
| Chicago crime data | `chatbot/data/community_crime_profile.csv` | Incident counts, violent crime %, night crime %, arrest rates |
| City 311 requests | `chatbot/data/311_requests_with_neighbourhood.csv` | Street light outages, vacant buildings, service response times |

---

## Risk Score Formula

```
combined_score = (crime_incidents   × 0.40)
               + (reddit_fear_ratio × 0.25)
               + (violent_crime_pct × 0.20)
               + (311_requests      × 0.10)
               + (street_lights     × 0.05)
```

Neighborhoods with all three data sources get a confident risk label (High / Medium / Lower Risk). Partial coverage is marked with an asterisk.

## Chatbot

The HerWay chatbot is powered by Azure OpenAI (GPT-4o) and knows about all 77 Chicago neighborhoods. It reasons across three data sources at once — crime records, Reddit community discussions, and 311 infrastructure data — to answer questions like:

- *"What's Austin like at night?"*
- *"Which neighborhoods have the most community concern?"*
- *"I'm a grad student moving to Chicago, which areas should I look into?"*

The chatbot avoids labeling areas as "safe" or "unsafe" — it presents what the data actually shows and is upfront when data is thin.

The API runs on Render and is called directly from the frontend at `/ask`.

## Running Locally

**Frontend**
```bash
cd frontend
npm install
npm start
```
Opens at `http://localhost:3000`. The chatbot will call the live Render API automatically.

**Backend (chatbot API)**
```bash
pip install -r chatbot/requirements.txt

# create a .env file at the project root
cp .env_example .env
# add your AZURE_OPENAI_KEY to .env

python chatbot/app.py
```
API runs at `http://localhost:5000/ask`.

**Data pipeline**
```bash
pip install -r requirements.txt

python pipeline/01_extract.py
python pipeline/02_locate.py
python pipeline/03_sentiment.py
python pipeline/04_merge.py
```

**Visualizations**
```bash
python visualizations/final_map.py
python visualizations/dashboard.py
python visualizations/gender_analysis.py
python visualizations/charts.py
```
Output files land in `outputs/`. Open any `.html` file in a browser — no server needed.

## Project Context

Built as part of the Soremo initiative at Illinois Tech. The goal is to understand urban safety from a community perspective, not just through official statistics — and to make that data accessible and understandable for people navigating Chicago.

All data is sourced from public Reddit posts and open city datasets. This project is for research purposes only.
