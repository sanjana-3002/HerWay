# HerWay — Chicago Women's Safety Analysis

A data pipeline that analyzes Reddit posts, city crime records, and 311 service requests to map neighborhood-level safety conditions in Chicago — with a focus on women's experiences.

**Author:** Sanjana Waghray  
**Institution:** Illinois Institute of Technology

## What This Project Does

Most safety apps rely only on official crime data. HerWay layers in real community voices from Reddit to capture what women actually feel and experience on the ground — fear of walking alone, street harassment, avoiding certain areas at night. The result is an interactive map that combines three different data sources into a single risk score per neighborhood.

## Data Sources

| Source | Location | What It Captures |
|--------|----------|-----------------|
| Reddit posts | `data/raw/chicago_safety_reddit.csv` | 1,218 posts from r/chicago, r/AskChicago, r/TwoXChromosomes |
| Chicago crime data | `data/raw/community_crime_profile.csv` | Incident counts, violent crime %, night crime %, arrest rates |
| City 311 requests | `data/raw/neighbourhood_311.csv` | Street light outages, abandoned buildings, service response times |

## How to Run

All scripts are run from the project root. Run them in order:

```bash
# 1. Re-scrape Reddit (only needed if you want fresh data)
python pipeline/01_extract.py

# 2. Extract neighborhoods from each post
python pipeline/02_locate.py

# 3. Run sentiment analysis (~5 mins, uses a RoBERTa model)
python pipeline/03_sentiment.py

# 4. Merge all three data sources
python pipeline/04_merge.py

# 5. Generate maps and visualizations
python visualizations/final_map.py
python visualizations/dashboard.py
python visualizations/gender_analysis.py
python visualizations/trend_analysis.py
python visualizations/charts.py
```

Output files land in `outputs/maps/` and `outputs/charts/`. Open any `.html` file in a browser — no server needed.

## Risk Score Formula

```
combined_score = (crime_incidents   × 0.40)
               + (reddit_fear_ratio × 0.25)
               + (violent_crime_pct × 0.20)
               + (311_requests      × 0.10)
               + (street_lights     × 0.05)
```

Neighborhoods with all three data sources get a confident risk label (High / Medium / Lower Risk). Partial coverage is marked with an asterisk.

## Project Context

Built as part of the Soremo initiative at Illinois Tech. The goal is to understand urban safety from a community perspective, not just through official statistics — and to make that data accessible to women navigating Chicago.

Data is sourced from public Reddit posts and open city datasets. This project is for research purposes only.
